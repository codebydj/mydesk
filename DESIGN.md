# Design system

The redesign turns the references into an editorial utility: warm canvas, charcoal type, thin rules, concise grouped navigation, and occasional gold for selection—not marketing hero elements or decorative metrics.

Tokens live in `src/styles/tokens.css`. The desktop shell uses a 232px sidebar and constrained content; mobile exposes primary destinations at the bottom and keeps actions at least 44px high. Spacing uses 4/8/12/16/24/32/48px. Panels are reserved for related data; rows stay flat and dense.

Every interactive element has keyboard focus. Status uses text in addition to colour. Dark mode uses separately chosen semantic surfaces. Motion is removed under reduced-motion preferences.
